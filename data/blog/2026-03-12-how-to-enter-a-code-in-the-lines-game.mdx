# How to enter promo codes in The Line Game
Promo codes are now in The Lines Game! Here's how to use them

First find the menu button in the top right of the screen:
![Menu button](/static/images/blog/how-to-enter-a-code-in-the-lines-game/screenshot-2.png)

Click it then click on "Settings":
![Settings option](/static/images/blog/how-to-enter-a-code-in-the-lines-game/screenshot-3.png)

On the Settings page scroll down till you find the "Promo Code" section:
![Promo Code section](/static/images/blog/how-to-enter-a-code-in-the-lines-game/screenshot-4.png)

From there you can enter your code and click redeem.

Have fun playing The Lines Game!
